------------------------------------------------------------------------
  ⚠  Production Checklist
------------------------------------------------------------------------
  1. Set a strong jwtSecret  (≥ 32 chars):
       --set secrets.jwtSecret="<strong-secret>"
  2. Disable bundled Postgres and point to a managed DB:
       --set postgres.enabled=false \
       --set config.databaseUrl="jdbc:postgresql://<host>:5432/<db>"
  3. Enable TLS on the Ingress:
       --set ingress.tls.enabled=true \
       --set ingress.tls.secretName="devops-dashboard-tls"
  4. Set your production domain:
       --set ingress.host="dashboard.yourdomain.com"
  5. Use an external secrets manager instead of plain values.
